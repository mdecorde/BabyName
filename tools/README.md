# Name Database Data

The Baby Name app utilizes names from these databases:

[nam_dict.txt](nam_dict.txt) with 40000+ entries is sourced from [heise.de](https://www.heise.de/ct/ftp/07/17/182/). Licensed as [GFDL-1.2-or-later](https://spdx.org/licenses/GFDL-1.2-or-later.html). The database quality is rather good and is from around 2008 and also contains detailed name frequencies.

Notes: Used by the Baby Name app. But the short forms of names are not used.

[common-forenames-by-country.csv](common-forenames-by-country.csv) with 2000+ entries is sourced from [sigpwned.com](https://sigpwned.com/2023/07/15/popular-names-by-country-dataset/). Licensed as [CC0-1.0](https://spdx.org/licenses/CC0-1.0). A list of the 5-20 popular names from different countries, regions, populations around the world. Data is from around 1990 until 2020.

Notes: Not in use by the Baby Name app (yet).

[Prenoms.txt](Prenoms.txt) with 10000+ entries is from from [lexique.org](http://www.lexique.org/public/prenoms.php) (link defunct). Licensed as "GNU" (we assume [GFDL-1.2-or-later](https://spdx.org/licenses/GFDL-1.2-or-later.html)). The data is from a big literature corpus from over 30 million books from 1950 to 2000 and contains also ancient and mythological names.

Notes: Only the uncommon names (ancient, mythological, astronomy, ..) names are used in the Baby Name app.
